# Web development Project 01 - *Album finder with Spotify API*

Submitted by:  **Mohamed Farah**
Time spent:  **24 hours** 

## An Overview

Album finder is a simple search tool: type an artist's name, hit search (or press Enter),
and see a grid of their albums with cover art, release date, and a direct link to open the album on Spotify.

## Features Implemented

- [x] **Search bar to looking up an artist by name**
- [x] **Fetches an access token from Spotify using the Client Credentials flow**
- [x] **Looks up the matching artist and retrieves their albums**
- [x] **Displays album cover art, title, and release date in a card layout**



## Tech Stack

- React19 + Vite - UI and build tooling
- TailwindCSS - utility-first styling
- React-Bootstrap - form controls, button, and card components
- Spotify web API - artist search and album data (Client Credentials flow)
